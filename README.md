# GyroSynth

Музыкальный синтезатор на основе данных гироскопа. Углы наклона устройства (X, Y, Z) управляют LFO синусоиды — вибрато, тремоло и фильтр в реальном времени.

## Структура

```
d:\GYRO\
├── app\
│   └── index.html   — веб-приложение (браузер)
├── firmware\
│   ├── platformio.ini  — конфиг PlatformIO
│   └── src\
│       └── main.cpp    — прошивка для ESP32-C3 Mini
└── README.md           — этот файл
```

## Быстрый старт (без ESP)

1. Открой `d:\GYRO\app\index.html` в Chrome/Edge/Firefox.
2. **Кликни в любую часть экрана** — браузер разблокирует звук.
3. Двигай мышкой — она эмулирует наклоны гироскопа.
4. На клавиатуре играй ноты: Z X C V B N M и Q W E R T Y U I.

## Подключение реального ESP32-C3 Mini через COM-порт

### 1. Прошивка ESP (PlatformIO)
Прошивка находится в папке `d:\GYRO\firmware`. Это PlatformIO проект.

1. Открой папку `d:\GYRO\firmware` в VS Code (PlatformIO должен распознать проект автоматически).
2. Плата: **ESP32-C3 Mini** (в `platformio.ini` уже прописано `board = esp32-c3`).
3. Пины гироскопа: **SDA → GPIO 8**, **SCL → GPIO 9** (уже прописано в `src/main.cpp`).
4. Скорость Serial: **115200**.
5. Нажми **Upload** в PlatformIO (стрелка вправо) — прошивка зальётся на ESP.

### 2. Подключение в браузере
1. Подключи ESP к компу по USB.
2. Открой `d:\GYRO\app\index.html` в **Chrome или Edge** (Web Serial API работает только в этих браузерах).
3. В правой панели найди карточку **"ESP / COM-порт"**.
4. Выбери порт из выпадающего списка и нажми **"Подключить ESP"**.
5. Наклоняй ESP — углы X, Y, Z будут приходить в браузер и управлять звуком.

> Firefox и Safari не поддерживают Web Serial API.

## Управление

- **LFO источник угла:** кнопка «X (tilt)» переключает X / Y / Z.
- **Цель модуляции:** кнопка «Частота (Hz)» переключает Частота / Амплитуда / Фильтр.
- **Глубина модуляции:** ползунок управляет силой влияния угла на звук.
- **Сглаживание угла:** делает изменения плавнее.
- **Запись WAV:** кнопка записи в нижней карточке сайдбара.

## Ableton / Max for Live

### Устройство GyroSynth для Ableton (Max for Live)

Файл `d:\GYRO\GyroSynth.maxpat` — это патч Max for Live. Чтобы использовать его в Ableton:

1. Установи **Max 8/9** (входит в Ableton Suite или докупается отдельно).
2. Открой `d:\GYRO\GyroSynth.maxpat` в Max.
   - Убедись, что файл `d:\GYRO\parseGyro.js` лежит в той же папке — он парсит строки гироскопа из COM-порта.
3. В патче нажми toggle **"ESP Serial"**, выбери COM-порт (например, `COM3`) и нажми **"open"**.
4. Наклоняй ESP32-C3 Mini — углы X, Y, Z будут отображаться в числах и управлять синусоидой.
5. **Источник угла:** меню X/Y/Z выбирает, какой угол управляет звуком.
6. **Цель модуляции:** меню выбирает, куда идёт модуляция — частота (вибрато), амплитуда (тремоло) или фильтр.
7. **Базовая частота** и **Глубина LFO** настраиваются диалами.
8. Когда патч готов, в Max: **File → Save As...** → сохраните как `.amxd` (например, `GyroSynth.amxd`).
9. Перетащите `.amxd` в сессию Ableton Live как аудио-эффект или инструмент.

> Для работы с реальным ESP32 прошейте его прошивкой из папки `d:\GYRO\firmware` (PlatformIO) и подключите по USB. Данные идут в COM-порт со скоростью 115200.
