# ESP32-C3 + MPU-6050 — Gyro Position Logger

Устройство на базе **ESP32-C3** и гироскоп-акселерометра **MPU-6050 (GY-521)**, которое:

- В реальном времени транслирует ориентацию (roll, pitch, yaw) на встроенную веб-страницу через WebSocket с частотой **30 Гц**.
- Сохраняет все данные на встроенную файловую систему (LittleFS) для последующего экспорта.
- При каждом включении автоматически подключается к указанной WiFi-точке (например, точке iPhone).
- Позволяет выбрать произвольный период на веб-странице и скачать данные в **CSV**.

## 🔌 Подключение

| GY-521 | ESP32-C3 DevKitM-1 |
|--------|-------------------|
| VCC    | 3.3V              |
| GND    | GND               |
| SDA    | GPIO20            |
| SCL    | GPIO21            |
| AD0    | GND (адрес 0x68)  |

> **Важно:** ESP32-C3 работает только с 3.3V. Не подавайте 5V на модуль GY-521!

## ⚙️ Настройка WiFi

Откройте `src/config.h` и измените параметры подключения:

```cpp
#define WIFI_SSID     "iPhone"   // Имя вашей точки iPhone
#define WIFI_PASS     "пароль"   // Пароль (пустая строка, если нет)
```

При каждом включении ESP32-C3:
1. Сканирует доступные сети
2. Ищет сеть с именем `WIFI_SSID`
3. Подключается, синхронизирует время по SNTP
4. Запускает HTTP-сервер (порт 80) и WebSocket (порт 81)

## 🌐 Веб-интерфейс

После подключения откройте в браузере `http://<IP-адрес>`.

Вы увидите:

- **3D-куб** — вращается в реальном времени по данным гироскопа
- **Карточки данных** — roll, pitch, yaw; ускорение (g); угловая скорость (dps); температура
- **Статус-бар** — состояние WebSocket, IP-адрес, размер накопленных данных
- **Экспорт CSV** — выбор периода (быстрые кнопки 5/15/30/60 мин или ручной ввод), кнопка скачивания
- **Кнопка Zero Yaw** — сброс нулевой позиции

## 💾 Логирование и экспорт

### Бинарное логирование (LittleFS)

- Запись: каждые **16 образцов** (≈ 0.53 с)
- Размер записи: **24 байта** (epoch, ms, accel, gyro, roll, pitch, yaw)
- Размер файла: до **700 КБ** (≈ 16 минут данных)
- Хранится до **3 файлов** (≈ 48 минут истории)
- Старые файлы удаляются автоматически

### Экспорт в CSV

На веб-странице выберите период и нажмите **Download CSV**. Файл содержит:

| Столбец | Описание |
|---------|----------|
| `timestamp` | Метка времени (по локальному часовому поясу клиента) |
| `ax_g`, `ay_g`, `az_g` | Ускорение по осям (g) |
| `gx_dps`, `gy_dps`, `gz_dps` | Угловая скорость (град/с) |
| `roll_deg`, `pitch_deg`, `yaw_deg` | Ориентация (градусы) |

> **Примечание:** экспорт по времени работает только после синхронизации SNTP. До синхронизации записи помечаются по времени работы устройства и не появятся в экспорте.

## 🚀 Сборка и загрузка

1. Установите расширение **PlatformIO** в VS Code
2. Откройте папку проекта `gyro/`
3. **PlatformIO: Build** — скачает библиотеки и скомпилирует
4. **PlatformIO: Upload** — загрузит на ESP32-C3
5. **PlatformIO: Monitor** — откройте Serial Monitor (115200 бод), чтобы увидеть IP-адрес

## 🐛 Возможные проблемы

| Проблема | Решение |
|----------|---------|
| MPU-6050 не найден | Проверьте подключение SDA→20, SCL→21; питание 3.3V |
| Точка iPhone не находится | Убедитесь, что имя и пароль совпадают с `config.h` |
| Данные не обновляются | Проверьте подключение по Serial Monitor (115200) |
| Веб-страница не загружается | Убедитесь, что браузер и ESP32 в одной сети |
